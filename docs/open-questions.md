# Открытые вопросы

Вопросы фиксируют неизвестные детали, а не отменяют согласованные требования из [основы проекта](project-foundation.md). Предложения имеют собственные `PROP-*` и не становятся обязательными до решения. Неопределённости детального проектирования не блокируют перенос контекста.

## Что требует решения сейчас

**Блокирующих вопросов по объёму каркаса нет.** После ревью PR №1 пользователь согласовал дизайн, необходимый набор технологий, bootstrap worker и Linux browser smoke и разрешил реализацию. Temurin 25.0.4.1+1 отдельно согласован вместо версии без Windows-дистрибутива. Фактические проверки и ограничения записываются в [отчёт](verification.md); недоступная проверка не считается успешной.

Доступ к HCh/Unitherm, ресурсы VPS, секреты и научные контракты для этого изменения не требуются. Развёртывание исключено. Ограничения инструментов и согласованные версии — в [технологической основе](technology-baseline.md).

25 октября 2026 года пользователь после обсуждения с научным экспертом принял необходимость упрощённой минимизации вместо возврата входа ([ADR-0010](adr/0010-prototype-minimization-solver.md)). Это решение уже не открытый вопрос. Перед отдельным изменением о решателе и его контрактах нужно закрыть `Q-SCI-004`–`Q-SCI-006` и `Q-DOM-002`; для каркаса они не блокирующие.
