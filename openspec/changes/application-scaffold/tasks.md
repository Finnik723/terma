REQ-BOOT-001, REQ-BOOT-004; SCN-BOOT-001, SCN-BOOT-006.

Добавить соответствующие unit/context и process smoke проверки. REQ-BOOT-002; SCN-BOOT-002, SCN-BOOT-003.
- [x] 2.3 Добавить только используемые JVM env-параметры и безопасный корневой `.env.example`, документировать реальное чтение окружения без обещания автоматической загрузки `.env`. **Результат/проверка:** смена локального порта действует, неправильный порт отклоняется, примеры/диагностика не содержат секретов и адресов сервера; локальные `.env` игнорируются Git. REQ-ENVCHK-001, REQ-ENVCHK-002.

REQ-ENVCHK-005; SCN-ENVCHK-007.

REQ-BOOT-003, REQ-BOOT-004, REQ-ENVCHK-001, REQ-ENVCHK-002.

REQ-BOOT-003; SCN-BOOT-004, SCN-BOOT-005.

REQ-BOOT-003, REQ-ENVCHK-003, REQ-ENVCHK-004; SCN-BOOT-004, SCN-BOOT-005.
- [x] 3.4 Дополнить Windows-инструкцию ручной проверкой экрана и HTTP, настройкой локального proxy и отсутствием поддержки обязательного Playwright на Windows 10. **Результат/проверка:** выполнен ручной путь «backend запущен → ответ → backend остановлен → ошибка»; browser smoke в Linux отдельно указан и не приписан Windows. REQ-ENVCHK-005; SCN-ENVCHK-007.
