# Архитектурные решения

«Принято» означает согласованное решение из исходной постановки или последующее явное решение пользователя; «Предложено» — вариант для дальнейшего дизайна; «Заменено» сохраняет прежнее решение для истории и указывает действующий ADR. Ни один статус сам по себе не означает, что решение реализовано или проверено работающим приложением.
