# Proposal

## Why

Технический application-scaffold уже реализован, собран и проверен, но контракт вычисления ещё не закреплён. Согласованное в web-обсуждении решение отделяет приложение от временного решателя и будущей подсистемы на исходниках HCh, не обещая совместимости с неизвестным внутренним API.

## What Changes

- Закрепить логический EquilibriumEngine, отдельные CalculateEquilibriumRequest/Result v1 и capabilities; подробный источник — [solver-contract.md](../../../docs/solver-contract.md), структуры — JSON Schema и синтетические примеры.
- Разделить версионируемые ссылки на химическую систему и термодинамические данные, фазовые определения и экземпляры фаз в результате.
- Описать семантическую проверку CLOSED-задачи с элементным входом, исходы вызова, баланс, свойства с единицами и provenance.
- Закрепить адаптер HCh, версионирование/историческую читаемость и границу переноса вне решателя в ADR-0011; исследование открытых свидетельств отделить от архитектурных выводов.
- Исправить устаревший статус каркаса и сценарий сравнения энергии: допустимое контрольное распределение принадлежит тесту, а не обязательному входу приложения.

**Объём — документационный контракт.** Исключены реализация движка/адаптера, Java DTO, оптимизатор и его зависимости, PostgreSQL/Kafka, UI, серии/смешение как код, deployment, merge и архивирование application-scaffold. LP, постоянные H/S/V и Hipparchus остаются кандидатом, не технологическим решением.

## Capabilities

### New Capabilities

- `equilibrium-engine-contract`: контракт одной задачи реактора, возможностей, результата, нормализации и совместимости при замене ядра. Специфицируется будущее поведение; наличие схем не означает его исполнения.

### Modified Capabilities

Нет. Основной каталог спецификаций пока пуст; application-scaffold остаётся неархивированным отдельным изменением с выполненными задачами.

## Impact

Меняются только документация, схемы и примеры. Источник решений — поручение пользователя; трассировка: REQ-SCI-003, REQ-SCI-005–REQ-SCI-012, REQ-ARCH-001–REQ-ARCH-002, REQ-RUN-001, REQ-CALC-001/REQ-CALC-003, новые REQ-CONTRACT-001–REQ-CONTRACT-008 и REQ-STAGE-005 в [основе проекта](../../../docs/project-foundation.md). [ADR-0011](../../../docs/adr/0011-equilibrium-contract-and-hch-adapter.md) дополняет ADR-0010, сохраняя замену ADR-0002. Поведение контракта уточняется в delta spec этого изменения; схема не задаёт HTTP API конкретного ядра.

Задачи относятся только к артефактам и их проверкам. Вычислительная приёмка SCN-SOLVER-001–SCN-SOLVER-003 остаётся будущей; archive/sync не выполняются.
