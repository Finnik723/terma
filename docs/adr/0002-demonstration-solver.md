# ADR-0002. Явная демонстрационная заглушка

Статус: **Принято**.

Основание: `REQ-GOAL-003`, `REQ-SCI-001`–`REQ-SCI-004` в [основе проекта](../project-foundation.md).

## Контекст

Ближайшая цель — проверить продуктовые сценарии, совместную работу и архитектуру. Настоящий решатель отложен; доступность HCh/Unitherm не гарантирована.

## Решение

Заглушка принимает одну задачу реактора, возвращает успешное техническое выполнение и входное состояние без изменений. Явно указываются тип/версия заглушки и демонстрационный характер результата, в том числе в UI и CSV. Заглушка не заявляет равновесия и не создаёт значения невычисленных свойств.

Для демонстрации переноса фазовое распределение веществ задаётся во входе. Заглушка не выводит его из одного элементного состава.

## Последствия

Можно проверить сквозной технический путь без ложных научных результатов. Научная достоверность не служит критерием демонстрации. Фальшивые эталонные расчёты не создаются. Заглушка не обещает проверить совместимость с будущим ядром.

## Проверка и открытые детали

`SCN-STUB-001`, `SCN-TRANSFER-001`, `DEMO-005`. Представление отсутствующих свойств и CSV уточняется в `Q-UI-001`; научные входы — `Q-DOM-002` в [открытых вопросах](../open-questions.md).
