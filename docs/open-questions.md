# Открытые вопросы

Вопросы фиксируют неизвестные детали, а не отменяют согласованные требования из [основы проекта](project-foundation.md). Предложения имеют собственные `PROP-*` и не становятся обязательными до решения. Неопределённости детального проектирования не блокируют перенос контекста.

## Что требует решения сейчас

**Каркас реализован и проверен.** PR №2 объединён в main, результаты отражены в [отчёте](verification.md); версии закреплены.

Согласованный [контракт v1](solver-contract.md) по ADR-0011 опубликован через PR №4. Дальнейшие технические задачи выполняются напрямую по поручению пользователя. Неизвестные API HCh/Unitherm требуют уточнения перед соответствующей интеграцией, но не блокируют независимые задачи приложения.

Необходимость минимизации принята в [ADR-0010](adr/0010-prototype-minimization-solver.md). CLOSED-постановка и внешний формат определены ADR-0011; `Q-SCI-004`–`Q-SCI-006` остаются для вычислительной реализации, параметров/данных и численной приёмки. Их решают перед соответствующей научной задачей, а не перед каждым техническим изменением.
