# Открытые вопросы

Вопросы фиксируют неизвестные детали, а не отменяют согласованные требования из [основы проекта](project-foundation.md). Предложения имеют собственные `PROP-*` и не становятся обязательными до решения. Неопределённости детального проектирования не блокируют перенос контекста.

## Что требует решения сейчас

**Блокирующих вопросов для подготовки нет.** OpenSpec 1.15.0 инициализирован; [изменение каркаса](../openspec/changes/application-scaffold/proposal.md) подготовлено для просмотра. Перед реализацией нужен просмотр предложения, новых delta specs, дизайна и задач и отдельное поручение на apply. В частности, предлагаются точные версии, однократный bootstrap worker и автоматический browser smoke в Linux CI, без требования Playwright на Windows 10.

Доступ к HCh/Unitherm, ресурсы VPS, секреты и научные контракты для этого изменения не требуются. Развёртывание исключено. Подтверждённые ограничения инструментов и предложения — в [технологической основе](technology-baseline.md); успешная сборка приложения пока не подтверждена.
