# Проекты

После входа Terma открывает список доступных проектов на `/`. В списке можно создать проект и открыть его по ссылке `/projects/{id}`. Карточка показывает название, автора, время создания и изменения. Прямую ссылку можно открыть после входа или перезагрузки страницы. [Задача №8](https://github.com/Finnik723/terma/issues/8)

## Хранение и доступ

Миграция `003-projects.xml` добавляет таблицы `project` и `project_member`. У проекта есть UUID, название, ссылка на учётную запись автора и два времени PostgreSQL. При создании времена совпадают. Одной транзакцией backend сохраняет проект и участие `OWNER` для UUID из сессии.

При каждом чтении backend проверяет наличие записи участия для UUID из сессии. Одинаковый ответ `404` используется для отсутствующего проекта и для проекта без доступа. Матрица действий по ролям относится к задаче №9. Управление участниками относится к задаче №10. [Матрица действий](https://github.com/Finnik723/terma/issues/9) · [Управление участниками](https://github.com/Finnik723/terma/issues/10)

## REST API

Список, создание и чтение по UUID доступны через `/api/projects`. Для создания нужен CSRF-токен, полученный для текущей сессии. Анонимный POST без действительного токена отклоняется с `403` до проверки аутентификации. [Контракт OpenAPI](api/projects.openapi.json) · [Сессии и CSRF](authentication.md)

Браузер передаёт имя показанной учётной записи в `X-Expected-Username`. При смене аккаунта в другой вкладке backend отвечает `409` до чтения или записи проекта, а интерфейс перечитывает сессию. Источник UUID для проверки прав — серверная сессия. Заголовок необязателен для других REST-клиентов.

## Проверки

Компонентные тесты проверяют пустой список, создание, повторное чтение после потери ответа, прямую ссылку и истечение сессии. Профиль `postgresql-it` проверяет REST, изоляцию двух учётных записей, атомарность создания и сохранность данных после перезапуска backend с настоящей PostgreSQL. Playwright проверяет создание и открытие в браузере, перезагрузку, смену учётной записи в соседней вкладке и отказ в открытии чужой ссылки. [Команды и среда проверок](development.md#linuxwindows-ci-и-пределы-проверок)
