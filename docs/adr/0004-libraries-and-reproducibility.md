# ADR-0004. Библиотеки, воспроизводимость и заменяемая подсистема

Статус: **Принято**.

Основание: `REQ-LIB-001`–`REQ-LIB-003`, `REQ-RUN-001`, `REQ-SCI-005`–`REQ-SCI-007` в [основе проекта](../project-foundation.md).

## Контекст

Общие и личные научные данные должны развиваться без изменения исторических запусков. Доступность HCh/Unitherm, их интерфейсы и взаимная связь пока неизвестны.

## Решение

Библиотеки поддерживают общие и личные варианты, копирование и редактирование. Опубликованные версии неизменяемы; правки готовятся в черновиках и публикуются новой версией. Общими библиотеками и версиями по умолчанию управляют пользователи с отдельно назначенными библиотечными привилегиями. Владение исследовательским проектом само по себе этих привилегий не предоставляет; точная модель назначения и области действия ещё открыта.

Запуск фиксирует точные входы, версию модели, версию библиотеки, тип/версию решателя, значимые настройки, результат, диагностику и статус. Смена версии по умолчанию не изменяет историю.

Адаптер допускает замену всей расчётной подсистемы, включая связанный с ядром доступ к научным данным. Не утверждается обязательный перенос Unitherm в PostgreSQL или известная совместимость с HCh. Предложение научного API будет опираться на проверенные открытые материалы с источниками; предположения помечаются.

## Последствия

Воспроизводимость постановки и происхождения учитывается с первых доменных контрактов. Она не доказывает научную достоверность упрощённой модели. Прототип теперь требует реальной минимизации по [ADR-0010](0010-prototype-minimization-solver.md); тип/версия алгоритма, значимые настройки и используемые данные сохраняются вместе с раздельными входом и результатом. Нельзя заранее зафиксировать внутреннюю научную схему по догадке или ограничить границу замены одним алгоритмом.
