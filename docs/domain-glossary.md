# Словарь домена

Словарь уточняет смысл терминов, но не задаёт таблицы БД, JSON-схемы, Java-классы или API конкретного научного ядра. Согласованные требования и предложения находятся в [основе проекта](project-foundation.md).

| Термин | Значение и границы | Связанные положения |
| --- | --- | --- |
| Учётная запись | Идентичность пользователя для аутентификации, авторства и проверки прав. Не равна проекту или роли в проекте | REQ-DOM-001, REQ-MVP-004, REQ-ACCESS-001 |
| Проект | Общая область исследовательской работы и совместного доступа; объединяет модели. Матрица прав ещё не утверждена | REQ-DOM-001, REQ-MVP-002, PROP-ACCESS-001 |
| Модель | Идентичность исследовательской постановки с историей версий и одной текущей версией. Не равна отдельному запуску | REQ-VER-001 |
| Версия модели | Неизменяемый сохранённый вариант постановки с автором, временем, происхождением и ссылкой на родителя. Точный состав снимка ещё уточняется | REQ-VER-001, PROP-VER-002 |
| Текущая версия | Единственная версия, на которую модель указывает как на актуальную. Смена этой ссылки не изменяет содержание исторических версий | REQ-VER-001, REQ-VER-005 |
| Родительская версия | Версия, на основе которой подготовлена следующая. Представление корня истории и связь родителя при создании отдельной модели требуют проектирования; происхождение от исходной модели и версии сохраняется | REQ-VER-001, REQ-VER-003 |
| Рабочая копия | Состояние редактирования в интерфейсе на основе открытой версии, включая несохранённые изменения. Не является автоматически сохранённой версией и не получает молча новую базу | REQ-DOM-001, REQ-VER-006, PROP-VER-001 |
| Устаревшая версия в интерфейсе | Открытая версия, которая уже не текущая. Её можно явно рассчитать, но сохранение в исходную модель требует атомарной проверки ожидаемой текущей версии | REQ-VER-004–REQ-VER-006 |
| Отдельная модель из версии | Новая самостоятельная модель из исторической версии, в том числе со своими изменениями при конфликте. Сохраняет происхождение. Это не явная ветка внутри исходной модели и не автоматическое слияние | REQ-VER-003, REQ-MVP-003 |
| Реактор | Отдельная равновесная задача с исходным состоянием и условиями. Может получать вещество из предыдущего реактора. В демонстрационном режиме задача решается заглушкой без утверждения равновесия | REQ-CALC-001, REQ-SCI-001 |
| Состав / состояние системы | Входные сведения о системе. Точные научные поля, единицы и формы задания ещё определяются. Для демонстрации фазового переноса включает заранее заданное распределение веществ по фазам | REQ-SCI-004, REQ-CALC-003 |
| Фаза | Предметное обозначение части системы, используемое в заданном фазовом распределении и выборе переноса. Классификация, идентификаторы и научная модель фаз пока не определены | REQ-SCI-004, PROP-TRANSFER-001 |
| Серия | Организованный набор расчётных задач с функциями температуры и давления. Независимые точки с одинаковым исходным составом — предложение, не окончательная семантика | REQ-CALC-002, PROP-SERIES-001 |
| Цепочка | Предложенная форма переноса между вычислительно зависимыми реакторами: линейный порядок и один проход. Форма графа в целом не утверждена | REQ-CALC-001, PROP-TRANSFER-001 |
| Перенос | Передача количеств вещества, включая растворитель, с учётом отправленной и оставшейся порций. Не сводится к копированию концентраций | REQ-CALC-003 |
| Термодинамическая библиотека | Набор научных данных с общей или личной областью использования, возможностью копирования и редактирования. Внутренняя структура Unitherm из этого понятия не следует | REQ-LIB-001, REQ-SCI-005–REQ-SCI-007 |
| Черновик библиотеки | Изменяемая подготовка научных данных перед публикацией новой версии. Детали совместного редактирования черновика открыты | REQ-LIB-002 |
| Опубликованная версия библиотеки | Неизменяемая версия научных данных, фиксируемая для запуска | REQ-LIB-002, REQ-RUN-001 |
| Версия библиотеки по умолчанию | Выбор для последующей работы в ещё не уточнённой области действия. Его изменение не заменяет версию у исторических запусков | REQ-LIB-002, REQ-LIB-003 |
| Запуск | Сохраняемое выполнение явно указанной версии модели с зафиксированными входами, библиотекой, решателем и настройками; имеет статус, диагностику и результаты. Граница запуска для серии/цепочки и его связь с дочерними задачами ещё уточняются | REQ-VER-004, REQ-RUN-001, REQ-RUN-002 |
| Зафиксированное задание | Представление точных входов и параметров выполнения, отделённое от изменяемой рабочей копии и внутреннего формата ядра. Контракт и правила хранения ещё не разработаны | REQ-ARCH-002, REQ-RUN-001 |
| Задача одного реактора | Единица обращения к решателю. Не тождественна всему запуску серии или цепочки | REQ-CALC-001 |
| Результат и диагностика | Сохранённый выход выполнения и сведения, объясняющие его исход. Технический успех может сопровождать демонстрационное состояние без научного решения | REQ-SCI-001–REQ-SCI-003, REQ-RUN-001 |
| Решатель | Исполнитель одной равновесной задачи. В ближайшем прототипе — явно версионированная заглушка; в будущем возможно другое ядро | REQ-CALC-001, REQ-SCI-001, REQ-SCI-006 |
| Оркестратор | Часть worker, управляющая последовательностью задач, сериями, переносом и зависимостями. Не делегирует всю цепочку решателю | REQ-CALC-001, REQ-ARCH-001 |
| Адаптер расчётной подсистемы | Граница интеграции задания и результата с конкретным ядром и связанными научными данными. Не утверждает известного API HCh или формата Unitherm | REQ-SCI-005–REQ-SCI-007, REQ-ARCH-002 |

Температура и давление сокращаются как T и P. Единицы, базис количеств, идентичность компонентов и веществ, точность и допустимые диапазоны предстоит согласовать с научным экспертом до доменных контрактов. Равновесие — научная цель, а не синоним статуса «успех».
